What & Why

Add a POST /generate-certificate endpoint that:

Accepts a user’s name
Generates a PDF in memory using pdf-lib
Uses a static PNG certificate as the background
Draws the user’s name centered horizontally
Returns the PDF as a download

No files are stored.

Done looks like
POST /generate-certificate with:
{ "name": "John Smith" }

Returns:

Download: certificate-John Smith.pdf

Behavior:

Name is perfectly centered horizontally
Positioned vertically to match the Canva placeholder
Font: custom OTF
Size auto-scales (50–70pt)
Color: white
Instant download
🔧 Important corrections (don’t skip these)
1. Page size MUST match image exactly

Do NOT hardcode dimensions.

Use the image itself:

const pngDims = bgImage.scale(1)
const page = pdfDoc.addPage([pngDims.width, pngDims.height])
2. Vertical alignment (more precise)

Instead of guessing:

“42–45%”

Lock it:

const y = page.getHeight() * 0.43

Then tweak slightly:

0.42 → lower
0.45 → higher
3. Font scaling (make it robust)

Do NOT just “guess 50–70”

Use this:

let fontSize = 70
const maxWidth = page.getWidth() * 0.7

while (
  font.widthOfTextAtSize(name, fontSize) > maxWidth &&
  fontSize > 50
) {
  fontSize -= 2
}
4. Sanitize filename (important)

Names can break headers.

const safeName = name.replace(/[^a-zA-Z0-9 ]/g, '')
🧠 Final Implementation (drop-in ready)
Install
npm install pdf-lib
Route (Express)
import express from 'express'
import fs from 'fs'
import path from 'path'
import { PDFDocument, rgb } from 'pdf-lib'

const router = express.Router()

router.post('/generate-certificate', async (req, res) => {
  try {
    const { name } = req.body

    if (!name || typeof name !== 'string') {
      return res.status(400).json({ error: 'Invalid name' })
    }

    const safeName = name.replace(/[^a-zA-Z0-9 ]/g, '')

    // Load assets
    const bgPath = path.join(__dirname, '../assets/certificate/certificate-bg.png')
    const fontPath = path.join(__dirname, '../assets/certificate/custom-font.otf')

    const bgBytes = fs.readFileSync(bgPath)
    const fontBytes = fs.readFileSync(fontPath)

    // Create PDF
    const pdfDoc = await PDFDocument.create()

    const bgImage = await pdfDoc.embedPng(bgBytes)
    const font = await pdfDoc.embedFont(fontBytes)

    const { width, height } = bgImage.scale(1)
    const page = pdfDoc.addPage([width, height])

    // Draw background
    page.drawImage(bgImage, {
      x: 0,
      y: 0,
      width,
      height,
    })

    // Font sizing
    let fontSize = 70
    const maxWidth = width * 0.7

    while (
      font.widthOfTextAtSize(name, fontSize) > maxWidth &&
      fontSize > 50
    ) {
      fontSize -= 2
    }

    // Center text
    const textWidth = font.widthOfTextAtSize(name, fontSize)
    const x = (width - textWidth) / 2

    // Vertical placement (tweak if needed)
    const y = height * 0.43

    // Draw name
    page.drawText(name, {
      x,
      y,
      size: fontSize,
      font,
      color: rgb(1, 1, 1),
    })

    const pdfBytes = await pdfDoc.save()

    res.setHeader('Content-Type', 'application/pdf')
    res.setHeader(
      'Content-Disposition',
      `attachment; filename="certificate-${safeName}.pdf"`
    )

    res.send(Buffer.from(pdfBytes))
  } catch (err) {
    console.error(err)
    res.status(500).json({ error: 'Failed to generate certificate' })
  }
})

export default router

⚠️ Common mistakes (avoid these)
❌ Hardcoding page size
❌ Using default font (ruins design)
❌ Not centering text properly
❌ Using bright white without testing contrast
❌ Not scaling long names
