Rules for the agent

Do not paraphrase or "improve" the prayer text. Render verbatim.
Slot markers in the prayer text use the form [slot_name]. Each slot maps to a Workbook field defined in the schema below. The agent's job is rendering template + data, not authoring text.
Where a slot's source list is empty, the surrounding sentence should be omitted gracefully — not rendered as "I repent especially of ." Pattern from build prompt's empty-state handling applies.
User-injected spans use the distinct visual treatment from the build prompt (info-color background, info-color text).

Note on count. The schema is 24 sections, larger than the previous 18 because the new prayers introduce categories Carmichael's didn't (idols as a separate list, harm done to others, named spirits as a discrete list, objects, future generation concerns) and split some of his combined fields (e.g., trauma is now event and sinful_response as two fields rather than a single combined entry; word curses are split by kind). Recommend not trying to compress this back to 18 — the prayer slots are the contract, and each section corresponds to text the user will actually see rendered.
Sections that did not survive from the old schema:

Judgments — folded into Section 2 (forgiveness) per the Catholic prayer's framing where judgment is one form of unforgiveness.
Covenants and vows — replaced by Section 7 (Vows & inner promises), which is a different concept. Catholic prayer treats vow-breaking under Confession; the slot in the new prayer is for unholy vows still in force, not vows broken.
Other sins — folded into Section 24 (Anything else) and Section 1 (Personal sins).
Influencers — dropped. The new prayers don't have an "influencers" slot. The theology has shifted away from "unholy soul tie with first introducer" toward straightforward repentance and renunciation. If you want to retain something like this, raise it before the agent removes it from the data model.
