---
name: Workbook editing and typography
description: User direction on obsolete workbook UI, organized content editing, and regular-only IvyOra.
---
The user no longer uses the legacy workbook resource UI and wants its obsolete prayer-link pages removed, while making workbook text editable in a clean, organized way that fits the overall product.

**Why:** The user says there are many places where text needs updating and adapting.

**How to apply:** Consolidate authored workbook content rather than introducing another competing UI or scattered copies. Distinguish obsolete page code from shared prayer functionality.

“The IvyOra font should NEVER be bolded. Just leave as is regular. NEVER bolded.”

**Why:** The user explicitly requires this throughout this product.

**How to apply:** Apply this to all IvyOra usage, including inherited heading and emphasis styles, not just the workbook.
